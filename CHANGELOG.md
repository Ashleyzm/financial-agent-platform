# Changelog

All notable changes to FinAgent Platform are documented in this file.

## [0.1.0] - 2026-08-19

### Added

- Asynchronous five-service Docker Compose platform and six-node LangGraph workflow.
- Provider-neutral market-data and LLM integrations with deterministic Mock defaults.
- Task persistence, traceable timelines, structured errors, Web console, and Docker E2E tests.
- Cross-platform start/stop scripts, provider replacement demo, failure demo, handover runbook, and F0 gate.

### Known limitations

- Prediction and risk remain rule-based prototypes.
- News, filings, industry data, authentication, quotas, and production observability are planned.
