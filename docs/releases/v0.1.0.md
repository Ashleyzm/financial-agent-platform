# FinAgent Platform v0.1.0

首个可接手的框架版本，完成从 Web 提交任务到异步多智能体报告的端到端闭环。

## 已交付

- FastAPI、Redis、独立 Worker、PostgreSQL 与 Web 控制台五服务运行链路。
- 六节点 LangGraph 工作流、任务持久化、检查点和可追踪时间线。
- Mock / AkShare 行情 Provider 与 Mock / OpenAI-compatible LLM Provider。
- Provider 中立契约、结构化模型输出、稳定错误码和模块路由。
- Windows 与 Linux/macOS 一键启动、健康等待和一键停止脚本。
- Provider 替换、模型超时失败、Docker 异步 E2E 与 CI 验收。
- 中英文 README、公网部署配置、接手手册和 F0 验收记录。

## 已知边界

- Prediction 与 Risk 当前仍是规则/Mock 基线，不代表专业投资模型。
- 新闻、公告、财报与产业数据 Provider 尚未形成完整业务能力。
- 暂未包含登录鉴权、配额、生产监控、商业部署和真实券商交易。
- 所有输出仅用于研究和教学，不构成投资建议或收益承诺。
